## 核心论文

- **面向演化 代理环境的真实网站接入**：该研究提供了153个可执行的Docker化Web环境，旨在为GUI代理提供稳定且真实的评估与强化学习训练环境，解决现有环境在功能深度和视觉保真度上的不足。 <a class="cite" href="https://huggingface.co/papers/2611.03634" target="_blank" rel="noopener noreferrer" data-cite="1. Web Harbor：面向演化 GUI 代理环境的真实网站接入｜Hugging Face 论文">1</a>
- **电商工具使用中长周期**：SLATE是一个针对电商工具使用中长周期API选择的大规模基准测试，旨在解决LLM代理在自动化复杂操作流程时面临的API选择与组合难题。 <a class="cite" href="https://arxiv.org/abs/2611.03982" target="_blank" rel="noopener noreferrer" data-cite="2. SLATE：电商工具使用中长周期 API 选择的超大规模基准｜arXiv cs.AI">2</a>
- **评估学生推理能力的 代理框架**：ProofPaths是一个结合评分标准与个性化交互访谈的AI代理框架，旨在评估学生对复杂问题的推理理解能力，而非仅仅验证答案的正确性。 <a class="cite" href="https://arxiv.org/abs/2611.03882" target="_blank" rel="noopener noreferrer" data-cite="3. Proof Paths：评估学生推理能力的 AI 代理框架｜arXiv cs.AI">3</a>
- **通过执行轨迹实现人机编码代理协作**：该研究提出了Vibetrace系统，通过可视化执行轨迹和交互干预，帮助用户更好地理解、监控并引导长时间运行的编码代理，促进人机协作。 <a class="cite" href="https://arxiv.org/abs/2611.04466" target="_blank" rel="noopener noreferrer" data-cite="4. 从观看到引导：通过执行轨迹实现人机编码代理协作｜arXiv cs.AI">4</a>
- **代理技能的源代码安全义务**：RuntimeTickets是一种协议，用于在第三方代理技能运行时强制执行和审计安全义务，防止恶意技能在合法工作流中隐藏数据泄露或输出篡改。 <a class="cite" href="https://arxiv.org/abs/2611.03772" target="_blank" rel="noopener noreferrer" data-cite="5. 运行时票据：代理技能的源代码安全义务｜arXiv cs.AI">5</a>
- **通用 系统的模型与策略路由研究**：该框架旨在通过动态选择和协调多样化的专用AI模型与策略，构建一个统一的通用人工智能系统，以提高性能和效率。 <a class="cite" href="https://huggingface.co/papers/2611.05275" target="_blank" rel="noopener noreferrer" data-cite="6. Route Anything：通用 AI 系统的模型与策略路由研究｜Hugging Face 论文">6</a>
