## 核心论文

- **用于评估智能体的多跳视频问答基准**：该基准测试旨在评估多模态大语言模型智能体在处理需要多跳多模态推理的复杂现实世界视频任务时的能力，填补了现有基准测试的空白。 <a class="cite" href="https://arxiv.org/abs/2609.21386" target="_blank" rel="noopener noreferrer" data-cite="1. Agent Vid Bench：用于评估MLLM智能体的多跳视频问答基准｜arXiv cs.AI">1</a>
- **使用 对智能体支付授权进行基准测试**：该基准测试通过复现公开夺旗赛中的攻击手段，评估工具使用型AI智能体在支付授权场景下的安全性，并验证了Open Agent Passport规范的有效性。 <a class="cite" href="https://huggingface.co/papers/2609.22076" target="_blank" rel="noopener noreferrer" data-cite="2. APort Vault：使用Open Agent Passport对AI智能体支付授权进行基准测试｜Hugging Face 论文">2</a>
- **和：迈向自动化端到端商业智能**：该研究利用大语言模型处理数据的能力，旨在实现从数据准备到回答商业问题的端到端自动化，以简化传统的商业智能工作流程。 <a class="cite" href="https://arxiv.org/abs/2609.20886" target="_blank" rel="noopener noreferrer" data-cite="3. BI-Agent和BI-Bench：迈向自动化端到端商业智能｜arXiv cs.AI">3</a>
- **图结构智能体技能的进化优化**：该研究提出了一种进化优化方法，旨在解决技能表示中的非结构化问题，提供显式的工作流指导并减少冗余，从而提升智能体的执行效率。 <a class="cite" href="https://huggingface.co/papers/2609.21749" target="_blank" rel="noopener noreferrer" data-cite="4. Graph Skill Evo：图结构智能体技能的进化优化｜Hugging Face 论文">4</a>
- **测量智能体会话中的隐私暴露位移**：该框架引入了隐私暴露位移的概念，通过预注册隐藏目标集并测量所有可见出口，解决了智能体会话中隐私评估的局部代理与真实暴露不匹配问题。 <a class="cite" href="https://arxiv.org/abs/2609.18864" target="_blank" rel="noopener noreferrer" data-cite="5. ASLEval：测量LLM智能体会话中的隐私暴露位移｜arXiv cs.AI">5</a>
- **可信智能体市场的凭证协议**：该协议通过连接认证、声誉和分配，旨在解决AI智能体市场中买家难以验证智能体性能的问题，为可信市场提供凭证机制。 <a class="cite" href="https://arxiv.org/abs/2609.21325" target="_blank" rel="noopener noreferrer" data-cite="6. LEGIT：可信AI智能体市场的凭证协议｜arXiv cs.AI">6</a>
