## 重点资讯

### 01 · OpenAI发布GPT-Realtime-2语音模型

OpenAI周四宣布API将新增语音智能功能，并推出基于GPT-5级推理的GPT-Realtime-2模型，旨在处理更复杂的用户请求。与此同时，马斯克起诉OpenAI案在法庭上披露了更多内幕，包括前CTO Mira Murati的证词以及前员工Rosie Campbell关于公司为追求商业化而牺牲安全性的指控。此外，Anthropic宣布与SpaceX达成合作，接入孟菲斯Colossus 1超级计算中心。

### 02 · 月之暗面完成20亿美元融资，投后估值突破200亿美元，累计融资近300亿。

北京AI实验室月之暗面（Kimi母公司）完成约20亿美元（约合136亿元）的D轮融资，投后估值突破200亿美元（约合1362亿元）。本轮由美团龙珠领投，水木资本、中国移动、CPE等参投，华峰资本担任财务顾问。这是中国大模型领域目前最大额的单轮融资，标志着月之暗面累计融资已近300亿元人民币，成为国内融资最多的AI创业公司。巨额融资彰显资本市场对中国开源大模型及月之暗面商业模式的信心。

### 03 · 瑞典AI初创公司Pit获得1600万美元种子轮融资，a16z领投。

由欧洲滑板车巨头Voi联合创始人创立的AI初创公司Pit，已获得1600万美元的种子轮融资，由风险投资机构a16z领投。该公司被视为斯德哥尔摩地区崛起的新星，其具体业务方向尚未完全公开。

## 核心论文

- **智能体在小时内构建推理加速器**：该论文展示了基于前沿模型的更新版多智能体系统，能够在80小时内自主构建TurboQuant推理加速器，处理任务规模比前一版本扩大80倍。 <a class="cite" href="https://arxiv.org/abs/2605.05170" target="_blank" rel="noopener noreferrer" data-cite="13. Design Conductor 2.0：智能体在80小时内构建Turbo Quant推理加速器｜arXiv cs.AI">13</a>
- **基于工具再利用的智能体创造性推理评估**：该基准测试通过工具的属性与 affordance 推理，评估AI Agent在创造性问题解决中的表现，填补了现有评估在创造性推理方面的空白。 <a class="cite" href="https://arxiv.org/abs/2605.02910" target="_blank" rel="noopener noreferrer" data-cite="14. Creativity Bench：基于工具再利用的智能体创造性推理评估｜arXiv cs.AI">14</a>
- **智能体工具使用的运行时安全评估与拦截**：该研究提出了一种运行时安全评估与拦截机制，旨在防范AI Agent在执行文件操作、数据库查询等工具调用时可能造成的不可逆危害。 <a class="cite" href="https://arxiv.org/abs/2605.04785" target="_blank" rel="noopener noreferrer" data-cite="15. Agent Trust：AI智能体工具使用的运行时安全评估与拦截｜arXiv cs.AI">15</a>
- **用于自动化代码质量评估的多智能体系统**：该系统基于Google Agent Development Kit构建，通过五层智能体架构自动分析Python代码质量，生成结构化的改进建议报告。 <a class="cite" href="https://arxiv.org/abs/2604.23088" target="_blank" rel="noopener noreferrer" data-cite="16. Code Broker：用于自动化代码质量评估的多智能体系统｜arXiv cs.AI">16</a>
