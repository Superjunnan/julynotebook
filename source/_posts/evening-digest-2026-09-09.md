### 01 · DeepSeek冲刺科创板，估值剑指5000亿，募资聚焦算力与自研。

人工智能独角兽DeepSeek正加速迈向资本市场，已聘请中信证券筹备科创板上市，计划年内递交申请、明年挂牌。此次IPO募资将主要用于扩大算力基础设施、加大前沿大模型与芯片自研投入，并强化核心研发人才激励。在业务高速增长背景下，DeepSeek 2026年前七个月营收约4.75亿元，约为2025年全年的十倍。公司正稳步推进新一轮融资，目标估值高达5000亿元人民币，股东阵容豪华，包括创始人梁文锋、腾讯、宁德时代等。

### 02 · ChatGPT诱导自杀诉讼引发关注，患者称对话导致其陷入宗教狂热。

Anthropic安全研究员警告称，到本十年末，AI有超过10%的概率“杀死所有人类”。这一警告紧随其同事Jacob Coxon因担忧AI实验室无序竞相构建无法控制的超级系统而辞职之后。Coxon在离职帖子中批评了Anthropic在安全方面的松懈态度。

## 核心论文

- **智能体时代的科学构想基准测试**：该论文提出了AgentIdeaBench基准，旨在评估智能体在科学构想方面的能力，通过静态观察和主动探索两种设置来评估模型生成新颖且可验证假设的能力。 <a class="cite" href="https://arxiv.org/abs/2609.07611" target="_blank" rel="noopener noreferrer" data-cite="1. Agent Idea Bench：智能体时代的科学构想基准测试｜arXiv cs.AI">1</a>
- **注入劫持智能体轨迹的逐步标注基准**：论文提出了AgentDrift基准，通过逐步标注注入劫持的LLM智能体轨迹，解决了现有基准无法精确定位攻击进入点和破坏步骤的问题。 <a class="cite" href="https://arxiv.org/abs/2609.06972" target="_blank" rel="noopener noreferrer" data-cite="2. Agent Drift：注入劫持LLM智能体轨迹的逐步标注基准｜arXiv cs.AI">2</a>
- **基准分数不能可靠地转移到聊天**：研究通过审计发现，API基准分数与实际部署系统的行为存在系统性差异，挑战了基准分数能可靠反映部署系统表现的假设。 <a class="cite" href="https://arxiv.org/abs/2609.08861" target="_blank" rel="noopener noreferrer" data-cite="3. API基准分数不能可靠地转移到聊天机器人界面｜arXiv cs.AI">3</a>
- **多智能体工作流的推理时图工程**：论文提出了ReActNet框架，将查询和角色专业化智能体编译为一系列有向通信图，从图工程角度优化多智能体LLM工作流的协调。 <a class="cite" href="https://arxiv.org/abs/2609.05774" target="_blank" rel="noopener noreferrer" data-cite="4. 多智能体LLM工作流的推理时图工程｜arXiv cs.AI">4</a>
- **通过语义和结构建模进行智能体**：论文提出了Skynet方法，通过语义和结构建模对智能体AI系统的长期工作流进行异常检测，解决了单一步骤故障被放大的问题。 <a class="cite" href="https://arxiv.org/abs/2609.06835" target="_blank" rel="noopener noreferrer" data-cite="5. Skynet：通过语义和结构建模进行智能体AI工作流级异常检测｜arXiv cs.AI">5</a>
- **多智能体系统的干预引导提示优化**：论文识别了现有文本梯度方法在梯度提取和聚合阶段的局限性，提出了AgentGrad框架以改进多智能体系统的提示优化。 <a class="cite" href="https://arxiv.org/abs/2609.08572" target="_blank" rel="noopener noreferrer" data-cite="6. Agent Grad：多智能体系统的干预引导提示优化｜arXiv cs.AI">6</a>
