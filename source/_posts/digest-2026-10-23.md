## 重点资讯

### 01 · OpenAI 推出 Decisions API，进入快速低成本决策模型市场。

OpenAI 首次向用户广泛开放其 Decisions API 模型，正式进入快速、低成本智能决策市场。这一举措正值 TypeSafe 公司因 Jev 模型估值达 76 亿美元之际，Jev 模型作为深度学习超级分类器，能快速在选项中做出选择并给出置信度评分。开发者发现该类决策模型可在多种工作流中替代 LLM，运行速度更快且成本大幅降低。标志着 AI 决策能力从通用对话向垂直场景的快速落地。

参考：<a class="cite" href="https://techcrunch.com/2026/10/22/openai-makes-its-jev-competitor-widely-available-as-decision-model-competition-heats-up/" target="_blank" rel="noopener noreferrer" data-cite="1. OpenAI 使其 Jev 竞争对手广泛可用，决策模型竞争加剧｜TechCrunch AI">1</a>、<a class="cite" href="https://openai.com/index/decisions-api" target="_blank" rel="noopener noreferrer" data-cite="2. 使用 Decisions API 构建更具响应性的应用｜OpenAI News">2</a>

### 02 · Meta 将未来押注于 Muse，构建自主 AI Agent 网络运行生活。

在 Meta 最新财报电话会议中，扎克伯格强调公司未来将致力于构建一个自主的 AI Agent 网络，负责购物、工作以及代理人类与其他 AI Agent 交流。Muse 作为个人 AI Agent 已向公众发布，Meta 正将其作为公司未来的核心战略。这一愿景引发了关于人类是否准备好通过机器人代理进行主要沟通的讨论。Meta 正从社交平台向 AI Agent 生态基础设施提供商转型。

参考：<a class="cite" href="https://www.theverge.com/tech/1016905/meta-earnings-fall-2026-muse-network" target="_blank" rel="noopener noreferrer" data-cite="4. 在 Meta 的未来版本中，我的 Muse 将呼叫你的 Muse｜The Verge AI">4</a>

### 03 · Uber 全员部署 ChatGPT Work，企业级 AI 应用规模扩大。

Uber 与 OpenAI 扩展合作，宣布其全球 30,000 名员工将全面使用 ChatGPT Work。该工具于今年 7 月推出，Uber 最初在 1,000 名员工中试点，涵盖财务、运营和产品等部门，现已扩展至全公司。

## 核心论文

- **通过模拟软件世界实现大规模 协作**：提出 Software World 框架，通过模拟真实软件生态系统中的多 Agent 协作，研究大规模推理计算下的协作有效性。 <a class="cite" href="https://arxiv.org/abs/2610.24061" target="_blank" rel="noopener noreferrer" data-cite="11. World of SWECraft: 通过模拟软件世界实现大规模 Agent 协作｜arXiv cs.AI">11</a>
- **多 药物发现引擎**：基于大语言模型构建多 Agent 药物发现引擎，旨在解决传统药物发现过程资源密集、耗时长的挑战。 <a class="cite" href="https://arxiv.org/abs/2610.16975" target="_blank" rel="noopener noreferrer" data-cite="14. MADDIE: 多 Agent 药物发现引擎｜arXiv cs.AI">14</a>
- **带有动态用户模拟的多轮编码 评估**：提出 SWE-DIVE 评估框架，通过动态用户模拟评估多轮交互中的编码 Agent 表现，解决现实场景中提示非结构化问题。 <a class="cite" href="https://arxiv.org/abs/2610.30047" target="_blank" rel="noopener noreferrer" data-cite="15. SWE-DIVE: 带有动态用户模拟的多轮编码 Agent 评估｜arXiv cs.AI">15</a>
- **用于多 协作的连续心智理论**：引入 ToM2Vec，通过连续推理 Token 学习抽象的心智理论，提升多 Agent 协作中的不确定性推理能力。 <a class="cite" href="https://arxiv.org/abs/2610.29934" target="_blank" rel="noopener noreferrer" data-cite="16. To M2 Vec: 用于多 Agent 协作的连续心智理论 Token｜arXiv cs.AI">16</a>
- **用于长时工具使用的演化自调优基准**：提出 TURTLE 方法，利用 LLM Agent 生成和演化长时工具使用任务，解决现有基准测试难以扩展的问题。 <a class="cite" href="https://arxiv.org/abs/2610.27307" target="_blank" rel="noopener noreferrer" data-cite="12. 用于长时工具使用的演化自调优基准｜arXiv cs.AI">12</a>
- **交互式 开发的编码 评估**：针对交互式扩展现实（XR）开发，提出 GenXR-Bench 评估基准，填补了编码 Agent 在长时程仓库级工程评估方面的空白。 <a class="cite" href="https://arxiv.org/abs/2610.29014" target="_blank" rel="noopener noreferrer" data-cite="13. Gen XR-Bench: 交互式 XR 开发的编码 Agent 评估｜arXiv cs.AI">13</a>
