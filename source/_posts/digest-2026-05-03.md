## 重点资讯

### 01 · 马斯克承认Grok蒸馏ChatGPT，自曝双标引发舆论哗然。

马斯克诉OpenAI案进入第四天庭审，马斯克在证人席上承认其公司xAI的Grok模型使用了OpenAI的模型进行训练，这一承认被外界视为“双标”现场。此前马斯克起诉OpenAI，指控其违背了非营利使命。庭审中，双方围绕邮件、短信及推特等证据展开激烈辩论，马斯克还警告AI可能毁灭人类。OpenAI方面则反驳称马斯克早已知晓公司结构。此案被视为AI行业发展的关键转折点。此案揭示了AI行业在商业化与伦理使命之间的深层矛盾，具有行业里程碑意义。

### 02 · ChatGPT Images2.0在印度市场表现强劲，成为最大用户群体。

OpenAI宣布其最新图像生成工具ChatGPT Images2.0发布后，印度迅速成为该功能最大的用户群体。数据显示，印度首周下载量约500万次，显著超过美国的200万次。该工具支持处理复杂提示词并生成含多语言文本的精细图像，强化了对印地语等非拉丁文本的渲染能力。尽管全球整体增长温和，但新兴市场如巴基斯坦、越南等地下载量增幅高达79%。新兴市场成为AI应用增长的新引擎，本地化语言支持与个性化创作需求是关键驱动力。

### 03 · GPT-5.5系统指令泄露，被禁止在无关联时提及特定生物。

OpenAI开源的Codex CLI代码揭示了GPT-5.5的部分底层逻辑。泄露的系统提示词中包含罕见指令，严禁模型在无明确关联时提及“哥布林”、小精灵、浣熊等特定生物。业界分析认为，这是针对新模型“幻觉”问题的定向修补，旨在解决模型在生成控制上的不稳定性。此前，GPT-5系列模型在对话中频繁出现无关的“哥布林”式比喻。大模型在进化过程中仍面临难以预测的输出偏差，底层指令优化成为控制幻觉的重要手段。

## 核心论文

- **协作代理推理工程（）**：CARE提出了一种系统化的方法论，通过可重用工件和分阶段流程，协调领域专家、开发者和助手代理来工程化设计大型语言模型代理，解决了科学领域代理开发的非结构化试错问题。 <a class="cite" href="https://arxiv.org/abs/2604.28043" target="_blank" rel="noopener noreferrer" data-cite="8. 协作代理推理工程（CARE）：一种系统化工程AI代理的三方设计方法论｜arXiv cs.AI">8</a>
- **面向患者的上下文感知多代理护栏**：CareGuardAI提出了一种上下文感知的多代理护栏机制，旨在缓解面向患者的LLM中的临床安全性和幻觉问题，通过增强模型对医疗语境的理解来提升医疗AI的可靠性。 <a class="cite" href="https://arxiv.org/abs/2604.26959" target="_blank" rel="noopener noreferrer" data-cite="10. Care Guard AI：面向患者LLM的上下文感知多代理护栏｜arXiv cs.AI">10</a>
- **通过自愈多代理实现自主流水线生成**：该研究提出了一种统一的五代理架构，能够从数据集和自然语言目标自动生成端到端的机器学习流水线，通过自我修复机制提高了流水线生成的效率、鲁棒性和可解释性。 <a class="cite" href="https://arxiv.org/abs/2604.27096" target="_blank" rel="noopener noreferrer" data-cite="12. Think it, Run it：通过自愈多代理AI实现自主ML流水线生成｜arXiv cs.AI">12</a>
- **多模态代理能否在交互式网站生**：InteractWeb-Bench是一个新的基准测试，旨在评估多模态代理在交互式网站生成中是否能够避免“盲目执行”的错误，即模型在语义不匹配的低质量指令下仍能正确执行。 <a class="cite" href="https://arxiv.org/abs/2604.27419" target="_blank" rel="noopener noreferrer" data-cite="9. Interact Web-Bench：多模态代理能否在交互式网站生成中避免盲目执…｜arXiv cs.AI">9</a>
- **在真实光学平台上进行端到端自**：该研究在真实光学平台上实现了端到端的自主科学发现，证明了AI代理能够在物理系统中通过持续修正问题、方法和假设来产生具有实验证据支持的非平凡结果。 <a class="cite" href="https://arxiv.org/abs/2604.27092" target="_blank" rel="noopener noreferrer" data-cite="7. 在真实光学平台上进行端到端自主科学发现｜arXiv cs.AI">7</a>
- **代理教育**：该研究提出了cc-self-train，一种通过动手项目构建来学习Claude Code的模块化交互式课程，旨在填补工具文档与实际掌握之间的鸿沟。 <a class="cite" href="https://arxiv.org/abs/2604.17460" target="_blank" rel="noopener noreferrer" data-cite="11. 代理教育：使用Claude Code来教授Claude Code｜arXiv cs.AI">11</a>
