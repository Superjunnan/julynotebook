## 热门资讯

### 01 · AI代理在金融检索与科研工具链中展现出显著性能提升，推动垂直领域自动化。

FinRetrieval基准测试显示，Claude在结构化数据API下准确率达90.8%，远超纯网页搜索的19.8%。同时，KARL和DARE等研究提出通过强化学习与分布感知检索优化企业搜索与R语言生态的代理能力。这些进展表明，AI代理正从通用对话向专业垂直领域深化，通过工具集成与数据分布优化提升可靠性。多源验证，技术突破显著，但实际落地效果仍需更多行业数据支撑。

### 02 · Anthropic因国防合同分歧被国防部列为供应链风险，OpenAI接…

Anthropic与五角大楼在AI模型控制权上产生分歧，导致其2000万美元合同破裂，国防部将其列为供应链风险。OpenAI随后接手，引发ChatGPT卸载量飙升295%。微软、谷歌和亚马逊随后确认，Anthropic的Claude模型对非国防客户保持可用。这一事件凸显了AI安全与军事应用之间的张力，同时也为OpenAI带来了意外的市场份额增长。单源待验证，但反映了国防AI采购的复杂性与市场格局的潜在变动。

## 核心论文 / 技术变革

- **KARL: Knowledge Agents via Reinforcement Learning**：提出KARLBench评估套件与迭代大批量离线强化学习范式，通过合成数据训练企业搜索代理，在成本-质量与延迟-质量权衡上超越Claude 4.6与GPT 5.2。 <a class="cite" href="https://arxiv.org/abs/2603.05218" target="_blank" rel="noopener noreferrer" data-cite="7. 论文平台原文">7</a><a class="cite" href="https://huggingface.co/papers/2603.05218" target="_blank" rel="noopener noreferrer" data-cite="9. 论文平台原文">9</a>
- **DARE: Aligning LLM Agents with the R Statistical Ecosystem**：引入分布感知检索模型DARE与R包知识库RPKB，提升R语言生态中函数检索的准确率，显著改善LLM代理在统计分析任务中的表现。 <a class="cite" href="https://arxiv.org/abs/2603.04743" target="_blank" rel="noopener noreferrer" data-cite="8. 论文平台原文">8</a><a class="cite" href="https://huggingface.co/papers/2603.04743" target="_blank" rel="noopener noreferrer" data-cite="10. 论文平台原文">10</a>
- **FinRetrieval: A Benchmark for Financial Data Retrieval**：构建包含500个金融检索问题的基准测试，揭示工具可用性对代理性能的主导作用，Claude在结构化数据API下准确率达90.8%。 <a class="cite" href="https://arxiv.org/abs/2603.04403" target="_blank" rel="noopener noreferrer" data-cite="11. 论文平台原文">11</a>
- **Evaluating the Search Agent in a Parallel World**：提出Mind-ParaWorld框架，通过合成未来场景与原子事实构建评估环境，解决静态基准过时与来源不可靠问题。 <a class="cite" href="https://arxiv.org/abs/2603.04751" target="_blank" rel="noopener noreferrer" data-cite="14. 在平行世界中评估搜索代理 · 论文平台">14</a>
- **Introducing GPT‑5.4**：发布GPT-5.4与GPT-5.4-Pro模型，提升文档编辑与表格建模能力，在内部基准中表现优于GPT-5.2。 <a class="cite" href="https://simonwillison.net/2026/Mar/5/introducing-gpt54/#atom-everything" target="_blank" rel="noopener noreferrer" data-cite="15. 社区来源原文">15</a>
