## 重点资讯

### 01 · 阿里通义实验室推出FIPO算法，精准识别关键Token以突破推理长度瓶颈。

阿里通义实验室Qwen Pilot团队近日推出了一种全新的算法FIPO（Future-KL Influenced Policy Optimization），旨在突破当前大模型在推理过程中面临的瓶颈问题。传统的强化学习方法(RLVR)在处理推理链中的每个 Token 时，往往无法区分出哪些 Token 对最终结果至关重要。因此，如何精准识别关键 Token 成为了一个亟待解决的难题。FIPO 算法引入了 Future-KL 机制。

## 核心论文

- **单智能体与多智能体在屏幕协作**：该论文探讨了在自动化视频分析中，单智能体与多智能体架构的性能差异，利用视觉语言模型处理多模态视频数据。 <a class="cite" href="https://arxiv.org/abs/2604.03631" target="_blank" rel="noopener noreferrer" data-cite="3. 单智能体与多智能体在屏幕协作学习行为自动化视频分析中的应用｜arXiv cs.AI">3</a>
- **从异构科学资源构建自进化智能体技能库**：论文提出 SkillFoundry 框架，旨在将异构科学资源转化为可复用的智能体技能库，解决科学智能体能力构建中的瓶颈。 <a class="cite" href="https://arxiv.org/abs/2604.03964" target="_blank" rel="noopener noreferrer" data-cite="4. SKILLFOUNDRY：从异构科学资源构建自进化智能体技能库｜arXiv cs.AI">4</a>
- **基于文件系统行为轨迹的智能体**：FileGram 框架通过分析文件系统行为轨迹，为在本地文件系统中运行的 AI 智能体提供记忆和个性化支持。 <a class="cite" href="https://arxiv.org/abs/2604.04901" target="_blank" rel="noopener noreferrer" data-cite="5. File Gram：基于文件系统行为轨迹的智能体个性化定位｜arXiv cs.AI">5</a>
- **记忆智能体**：论文提出 Memory Intelligence Agent (MIA) 框架，通过 Manager-Planner-Executor 架构解决深度研究智能体在记忆进化与存储成本上的问题。 <a class="cite" href="https://arxiv.org/abs/2604.04503" target="_blank" rel="noopener noreferrer" data-cite="6. 记忆智能体｜arXiv cs.AI">6</a>
- **扩展团队还是扩展时间？多智能**：该研究提出了 LLM 多智能体系统的概念性扩展视图，探讨了团队规模与终身学习能力之间的交互关系。 <a class="cite" href="https://arxiv.org/abs/2604.03295" target="_blank" rel="noopener noreferrer" data-cite="7. 扩展团队还是扩展时间？LLM多智能体系统中的终身学习｜arXiv cs.AI">7</a>
- **编码智能体架构的源代码分类法**：论文对 LLM 编码智能体的控制循环、工具定义、状态管理等支撑代码进行了分类，填补了架构理解上的空白。 <a class="cite" href="https://arxiv.org/abs/2604.03515" target="_blank" rel="noopener noreferrer" data-cite="8. Inside the Scaffold：编码智能体架构的源代码分类法｜arXiv cs.AI">8</a>
