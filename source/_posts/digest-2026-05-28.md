### 01 · OpenAI 推理模型独立攻克 80 年数学难题，实现从辅助到自主的科学发现。

## 核心论文

- **视觉规格到 应用编码代理的端到端基准**：VISTA 是一个用于评估基于 LLM 的代理端到端 Web 应用生成能力的基准。与以往专注于算法任务的代码生成基准不同，VISTA 针对现实的以 UI 为中心的发展，要求代理从未充分指定的输入中生成功能性和视觉上连贯的应用程序。 <a class="cite" href="https://arxiv.org/abs/2605.26144" target="_blank" rel="noopener noreferrer" data-cite="12. VISTA: 视觉规格到 Web 应用编码代理的端到端基准｜arXiv cs.AI">12</a>
- **内核生成中自进化**：论文介绍了 CUDAnalyst，这是一个用于控制、生成级归因的统一分析层，通过轨迹冻结和选择性反馈注入，将规划决策归因于反馈组件。 <a class="cite" href="https://arxiv.org/abs/2605.26720" target="_blank" rel="noopener noreferrer" data-cite="13. CUDA 内核生成中自进化 LLM 代理的反馈到规划决策｜arXiv cs.AI">13</a>
- **大规模代理系统渗透测试的教训**：论文探讨了随着 AI 系统自主性和执行能力的增强，其安全漏洞数量持续上升的现象。执行型 AI 代理本质上是无界的、自修改的程序，与计算栈的多个层进行广泛交互。 <a class="cite" href="https://arxiv.org/abs/2605.27042" target="_blank" rel="noopener noreferrer" data-cite="14. 大规模代理系统渗透测试的教训｜arXiv cs.AI">14</a>
- **检测缺陷 生成同行评审的工具增强代理**：TADDLE 是一个用于检测缺陷 LLM 生成同行评审的工具增强代理，并提供了该任务的首个专家标注基准。 <a class="cite" href="https://arxiv.org/abs/2605.26911" target="_blank" rel="noopener noreferrer" data-cite="15. TADDLE: 检测缺陷 LLM 生成同行评审的工具增强代理｜arXiv cs.AI">15</a>
- **基于多代理系统的通用 优化框架**：UnityMAS-O 提供了一个统一的强化学习接口，用于优化 LLM 基于多代理系统，解决了大多数系统仍由提示、工具和控制规则手动编排的问题。 <a class="cite" href="https://arxiv.org/abs/2605.26646" target="_blank" rel="noopener noreferrer" data-cite="16. Unity MAS-O: LLM 基于多代理系统的通用 RL 优化框架｜arXiv cs.AI">16</a>
- **你的代理也会老化**：论文指出，长期运行的 AI 代理作为持久运行系统被部署时，其可靠性会随时间变化。即使模型权重冻结，代理的有效状态也会因压缩交互历史、从增长的记忆存储中检索、更新事实和例行维护而不断变化。 <a class="cite" href="https://arxiv.org/abs/2605.26302" target="_blank" rel="noopener noreferrer" data-cite="17. 你的代理也会老化：部署系统的代理寿命工程｜arXiv cs.AI">17</a>
