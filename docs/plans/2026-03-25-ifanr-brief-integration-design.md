# 爱范儿早报混合源接入设计

## 背景

当前日报链路已经区分早报与晚报 edition，并具备：

- 自动源抓取
- 历史去重
- 预归并
- 事件级打分
- 重点资讯不足 3 条的兜底补齐

`爱范儿早报` 与现有纯资讯源不同：它是一篇人工编辑的 roundup，单篇文章中包含多条简讯标题、摘要与部分原文引用。如果直接把整篇早报当作一条候选，会把多个不相干事件混成一个 topic，削弱现有聚类、shortlist 与成稿效果。

## 目标

把 `爱范儿早报` 作为“混合模式”来源接入：

- 默认作为候选补充源
- 同时可作为交叉验证/平台背书源
- 对 AI 行业意义显著、涉及头部 AI 公司/模型的条目，可在必要时作为单源条目保留
- 严格过滤非 AI 内容，避免消费电子、汽车、泛科技条目污染日报

## 方案选择

### 方案 A：把整篇早报文章作为普通 page_scrape 条目

优点：
- 接入快

缺点：
- 一篇文章包含多个话题
- 会把多个不相干事件混入同一条候选
- LLM 聚类输入质量差

不采用。

### 方案 B：新增 `ifanr_morning_brief` 解析器，拆解单篇 roundup 为多条候选

优点：
- 与现有 candidate -> topic -> shortlist 结构天然兼容
- 可以复用当前的确定性去重、打分、历史过滤
- 既能作为独立候选，也能在同题时作为额外佐证

缺点：
- 需要站点专用解析逻辑

采用本方案。

## 数据流设计

1. `sources.yml` 新增 `ifanr-brief` 来源
   - `url` 指向 `https://www.ifanr.com/category/ifanrnews`
   - `ingestion_mode: page_scrape`
   - `parser: ifanr_morning_brief`
   - `group: domestic_media`
   - `preferred_in: evening`
   - 权重低于 `AIBase / 量子位 / 机器之心`

2. 抓取 category 页上的“早报”文章链接
   - 只保留标题含 `早报｜`
   - 限制近期少量文章，避免多篇 roundup 同时放大噪声

3. 对每篇早报详情页进行专用拆解
   - 提取每条简讯标题
   - 提取对应摘要段落
   - 优先提取该条简讯绑定的外部原文链接
   - 若无明确外链，则退回爱范儿文章链接

4. 对拆出的每条简讯执行 AI 过滤
   - 标题关键词过滤
   - 摘要关键词过滤
   - 头部公司 / 模型实体命中优先
   - 行业价值事件类型优先

5. 拆出的条目进入现有链路
   - 去重
   - 历史过滤
   - 事件聚类
   - topic scorecard
   - shortlist
   - 成稿

## AI 过滤规则

### 基础 AI 命中

必须至少满足其一：

- 标题命中 AI 关键词
- 摘要命中 AI 关键词
- 命中头部 AI 公司 / 模型实体

### 头部实体优先

命中以下实体之一时，允许较弱的关键词命中仍保留：

- OpenAI
- Anthropic
- Google / DeepMind
- Meta
- xAI
- 英伟达
- MiniMax
- 智谱
- 阿里 / 通义 / Qwen
- 字节 / 豆包 / Seed
- 腾讯 / 混元
- Kimi / 月之暗面
- DeepSeek
- 百度 / 文心 / 千帆
- 华为 / 盘古
- 小米

### 行业价值优先

以下事件类型加分：

- 模型/产品发布
- API / 平台更新
- 商业化/融资/客户落地
- 芯片/算力/基础设施
- 政策/监管/法务
- 安全/评测/重大争议

## 评分与角色

`爱范儿早报` 条目默认：

- 候选补充权重较低
- 进入 topic 后可作为交叉验证补分
- 作为单源条目时，需要满足：
  - 头部 AI 公司/模型命中
  - 高行业价值
  - 明确 AI 相关

优先进入 `其他快讯`；只有在 `重点资讯` 不足且综合分足够时，才允许补到 `重点资讯`。

## 工程边界

- 不引入新 LLM 节点
- 不改变现有 edition 架构
- 不把 `爱范儿早报` 整篇作为单 candidate
- 不为它单独新增前端模板

## 测试与验收

至少新增并通过：

1. `ifanr_morning_brief` 解析测试
   - 能从示例 HTML 中拆出多条候选
2. AI 过滤测试
   - 能过滤非 AI 条目
3. 来源注册测试
   - 新来源在晚报偏置中可运行
4. 全量 `npm run test:digest`
5. `npm run clean && npm run build`
6. 重启本地服务并请求首页 / 日报列表 / 一篇晚报详情
