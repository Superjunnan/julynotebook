# 全站页面收尾统一设计

## 背景

当前站点已经完成了首页、日报列表、笔记列表、详情页和桌面固定左栏的大部分改造，但全站仍有几处体验不一致：

- 首页日报卡片仍保留旧的“今日重点”口径，卡片尾部留白偏松。
- 详情页的 `关键信号` 虽然已压缩为编号，但视觉分量仍偏重。
- `迭代记录` 仍未完全纳入同一套移动端页头和正文密度规则。

## 目标

本轮统一收尾以下页面：

- 首页
- 日报列表
- 笔记列表
- 日报 / 笔记 / 普通详情页
- 迭代记录
要求：

- 所有移动端顶部固定栏统一只显示当前页面短名称。
- 首页日报卡片改为 `今日主线` 口径，并提高卡片信息密度。
- 详情页继续保留右上角目录入口，但把 `关键信号` 压缩成更轻的编号提示。
- `迭代记录` 对齐详情页的首屏节奏。

## 非目标

- 不重写 Hexo / NexT 模板体系。
- 不重新设计桌面固定左栏方案。
- 不更改 digest 生成逻辑和内容筛选逻辑。
## 推荐方案

采用“统一壳层收尾”方案：

1. 使用现有 `app-shell.js` 的视图识别，把 `iteration-log` 和详情页继续纳入统一页头标题逻辑。
2. 通过 `app-shell.styl` 收紧移动端页头背景、间距和按钮布局，不另起一套样式系统。
3. 通过 `index.njk + app-cards.styl` 调整首页日报卡片标签和尾部密度。
4. 通过 `detail-view.styl + post-layout.js` 继续压缩详情页 `关键信号` 显示。

## 关键设计

### 1. 页头统一

- `daily-post` 固定显示 `AI 日报`
- `note-post` 固定显示 `AI 笔记`
- `iteration-log` 固定显示 `迭代记录`
- 普通页面使用页面标题，但移动端顶部视觉不再强调站点品牌栏

视觉上：

- 顶栏保留，但改成更轻的浅底/弱毛玻璃，不再形成沉重黑底感。
- 移动端详情页继续只保留右上角目录按钮，不恢复底部浮动菜单。

### 2. 首页卡片统一

- 日报卡片标题下的说明口径统一为 `今日主线：`
- 摘要仍优先使用有序分点，缺少列表时也显示更紧凑的两三行摘要
- 卡片尾部 `阅读全文` 行收紧上下间距，减少无效底部留白

### 3. 详情页统一

- 保留当前卡片式正文头部
- `关键信号` 继续只显示编号，不展示长文本
- 编号胶囊改小、间距更紧，作为“提示”而不是主内容块

### 4. 迭代记录

- `迭代记录` 保持时间线，但首屏顶部节奏与详情页一致
- 移动端顶部栏统一只显示页面名

## 风险与控制

### 风险 1：普通页面标题逻辑和详情页逻辑互相污染

控制方式：

- 样式层优先使用 `body.app-view-*` 类名区分，而不是扩大 `.detail-page` 的影响范围。

### 风险 2：首页卡片改动影响现有摘要测试

控制方式：

- 先写回归测试，固定 `今日主线` 文案和卡片尾部样式，再调整模板和样式。

## 验收标准

- 首页日报卡片显示 `今日主线：`
- 首页卡片底部留白较当前更紧凑
- 详情页 `关键信号` 仅显示轻量编号
- 移动端 `AI 日报 / AI 笔记 / 迭代记录` 顶部栏只显示页面短名称
- `node --test tests/digest/daily-post-ui-regression.test.mjs` 通过
- `npm run test:digest` 通过
- 本地站点重启后，首页、日报列表、笔记列表、详情页、迭代记录均可正常访问
